# 模型训练与定点约定

## 为什么重训

保留版使用共用的DW空间层和head，主要由stem/PW调整颜色；新版本为四套独立分支，每套都学习stem、四组DW/PW及输出head。输入仍逐像素720p，所有隐藏特征同分辨率，不做2×2池化或广播。

每套为stem 1×1 3→6，四组DW 3×3/PW 1×1 6→6，膨胀率1/2/4/8，最后1×1有符号RGB增量与原RGB相加。感受野31×31。卷积权重396个/风格；四套运行时复用同一硬件，每次由真实RISC-V加载目标风格全体参数。风格数增加主要增加权重ROM；由共用常量层改为任意运行时参数则会增加寄存器、选择器及路由资源。

## 本轮训练

代码在 `pycode/painterly_style/`，训练数据固定512张，沿用既有训练/留出划分，用户测试图不进入训练。四个较大的感知教师重新训练，各1600步；学生第一阶段14000步，再做3000步完整折叠定点精修。新的教师以真实风格参考、VGG特征Gram损失及内容约束训练；学生结合教师输出、参考风格与内容损失，不只拟合旧轻量模型。

增强覆盖0.45–1.35曝光、gamma及亮矩形，模拟暗环境和画面中亮屏；水墨增加低彩度与纸白约束。160×160只是训练裁剪，推理不因此降分辨率。原已认可的模型与bit保留。

梵高鼓励有方向的笔触和色彩；水墨鼓励墨阶、纸白和晕染。最终实际照片对照在 `build/quality/`，每张四列为原图、保留C6、新教师、新学生。不能把训练参考或教师效果当作FPGA学生效果。小模型、局部感受野和逐像素原图残差仍会限制笔触大小与结构重绘，画质需用户实屏确认。

## 数值契约

输入RGB565在FPGA展开为RGB888；核心打包低字节R、中字节G、高字节B。内部特征uint8，隐层比例6/255；首层输入比例1/255。卷积权重int8，偏置与累加有符号22位，舍入扩为23位，按通道右移0–20，负值归零及255饱和。head允许−510..510，再与原RGB相加并饱和。

每通道量化移位同时满足权重范围与保守界限：`abs(bias)+255*sum(abs(weight)) < 2^21`，计入系数量化舍入余量。最终不得裁剪超范围权重。PW两数和18位、四数和19位、总和20位；DW三tap点积19位，含偏置累计22位。FP32卷积的整数运算也保持精确整数范围，软件关闭TF32。

冻结BN与条件仿射折叠进权重/偏置；这不等同于硬件实时IN。完整折叠QAT、NumPy int64、Torch整数路径需要逐值一致；最终检查点重新导出后须与ROM/NPZ一致。

每风格712B有效参数，736B对齐；四组2944B ROM，216次配置写入/模型。每层地址高4位选择层，低地址区为权重按4字节写入，0x400区为逐通道偏置，0x800区为右移。各值采用固定通道/字节写者，避免已知动态数组局部写映射问题。
