# 四风格资源优化与再次电气复查（2026-10-19）

本轮只优化 `uart_art_styles` 的卷积实现；四组训练参数、12通道五层、逐层镜像边界、默认1280×720、显式640×480、100MHz CNN、2Mbps UART和720p30显示均保持。其余Ti60项目、Xilinx、demo V7/V9未改。未打开实际串口/JTAG、未下载或固化。

## 实际布局布线结果

| 配置 | RAM10（前→后） | DSP（前→后） | XLR（前→后） | 新最小 setup / hold |
| --- | --- | --- | --- | --- |
| 720p | 245→221 / 256 | 153→144 / 160 | 26095→26161 / 60800 | +0.376 / +0.028 ns |
| vga | 245→221 / 256 | 153→144 / 160 | 26069→26212 / 60800 | +0.395 / +0.026 ns |

RAM10从245降至221，释放24块（原占用的9.8%），余35块；DSP从153降至144，释放9个，余16个。XLR有所增加，用更充足的逻辑资源换取紧缺RAM和DSP；没有把所有种类资源都减少。两配置分别实际执行Efinity 2026.1.132 / Ti60F225 I3综合、接口、布局布线、全部工作时钟原生STA及配置生成，单任务四线程。

## 改了什么，为什么不改变图像

- 五层的偏置表只有4或16项。显式使用 `syn_romstyle="logic"`，保留原同步读取寄存器和五级偏置流水，避免浅而宽的表占用24块RAM10。权重ROM与行缓存布局不改。
- 第一层九个uint8×int8全精度乘法显式 `syn_use_dsp="no"`，其余144个乘法保留DSP。乘积位宽、有符号性、时钟使能、加法/累加、舍入、饱和和握手周期保持原样。
- 这是存储/算术映射优化，不是重新训练、减少通道、压低位宽、降低分辨率或增加时分复用。模型和15个ROM文件与基线逐字节相同。

本机官方Efinity帮助的 `syn-attr-romstyle.html`、`syn-attr-use-dsp.html`明确记录了上述两个属性；实际map和最终布局资源均核对。

## 功能与周期核对

四模型首层1292像素、完整五层四模型128×37的18944个保留像素、COBS→DDR→四种真实模型→显示提交联合测试通过。背压、CRC/半帧/ABORT、忙BEGIN、重复END、最终写响应、失败保留前台及恢复继续通过。五层测试仍4259808周期；联合测试完成时间与基线相同。

生产高度另外运行1280×720全局坐标下梵高左右两个96×720条带：46080保留像素、138240内部像素，6991610周期，与优化前一致。范围是一个模型的两个条带，不是全帧SoC或实板FPS测试。原四模型全720p/VGA的软件分条整数零误差记录因参数和参考未变继续有效，未冒充本轮全尺寸RTL重跑。

联合测试原先遗留了“单模型重复四槽”的scope文字，代码实际一直按catalog.SELECTED生成并核对四组不同模型；本轮仅更正这处报告描述，实际测试/输入/权重未改。

## 电气与时序复查

只以用户指定 `TI60F225I3-V4_SCH-20261012（原理图）.pdf`（SHA256 `8cf636e4253848cf2bb8a612031bd0fd7e4183a8c59ae7be71b1008aaf669b41`）为依据，复看第3页供电、第10/13页HDMI、第11页相机，并逐项检查最终66脚/79脚和12个Bank。

| 接口 | 核对 |
| --- | --- |
| UART、四按键 | 3.3V；RX R4输入、TX R14输出；KEY0..3=C4/P14/N14/A3，仅输入 |
| DDR3 | Bank3B/4A/4B=1.5V SSTL；DQ/DQS双向及OE、DM/控制方向、原厂PHY/PLL不改 |
| 时钟、TMDS | 25/27MHz J2/H2输入1.8V；TMDS Bank3A=1.8V专用LVDS TX，四路P/N反相补偿保留 |
| 摄像头项目（本轮只读复核） | SC431HAI配套模组J4；SCL D12/SDA B14=3.3V开漏，OUT恒0；RESET C12=3.3V高有效；MIPI专用RX、Bank2A/2B=1.2V |
| 未用脚、J8 | 未用GPIO为输入弱上拉，无新增输出驱动。J8不是UART，使用板载USB串口 |

本项目两配置的 `.peri.xml` 与正确引脚资源优化前基线逐字节相同；生产源清单中仅 `art_conv3x3.sv` 改变。SDC保留全部PLL/PHY时钟、12条单比特首级精确例外、116条Gray指针最大延迟；没有通过放宽时钟/切断路径获得通过。两套最终全部setup/hold关系非负。其他四套旧项目bit/RTL/IP/固件及相关配置119个冻结文件指纹未变。

保留原HDMI邻近GPIO耦合警告。软件核对不等于实际电源、电流、温升、线路质量或整机并发已验收，不能保证零损坏风险；未知Flash程序的上电行为也不由新bit生成决定。现有J4和跳线接法沿用用户已确认的状态，不重复要求确认。
