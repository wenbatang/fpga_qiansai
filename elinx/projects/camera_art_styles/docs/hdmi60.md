Programmer选 **JTAG**，加载上面这一份 `ti60_camera.bit`。固件和四组权重已包含，不另烧firmware、不需要PC串口传图。下载后先显示启动彩条；CPU完成摄像头初始化、采集和首帧推理后，应切到居中的风格画。

模组继续用已确认的SC431HAI配套模组／J4，J2/J3均2–3，不改接法。不要带电插拔排线；带模组重新上电前仍应明确未知Flash的启动内容或使用厂家确认的启动方式，易失性JTAG程序不会改变下次上电加载的内容。本轮仅生成本地文件，未代为下载或固化。

KEY0梵高厚涂、KEY1彩色剪纸、KEY2复古漫画、KEY3水墨；KEY0+KEY3长按一秒逻辑复位。叠加的C为每秒DDR完整采集发布数、I为真实推理完成数、H60为配置显示刷新率。彩条一直存在表示尚无完整处理帧，不能据此认定摄像头已经正常采集；可观察C/I是否开始变化。

## 改动范围

- 摄像头仍1920×1080 RAW10／四lane，经原2×2 Bayer和裁剪得到 **640×480**；原十二通道CNN、运行时权重加载、Sapphire3.4.0、三原画／双输出DDR所有权和四模型不变。
- HDMI改为 **1280×720p60**，640×480处理画面不缩放、居中显示。74.25MHz像素／371.25MHz串化半速时钟保持，水平前沿1760→110，1650×750总周期，+HS/+VS。
- 发送端与用户已实屏确认的UART60版逐字节相同：原厂V7 HDMI TX、RGB／AVI VIC4、四对P/N反相。原厂文件和demo均未改，没有解密或IP升级。
- 新显示模块在首帧发布前出八色彩条，像素扫描不等待DDR校准；UI／CPU／MIPI／摄像头控制仍等待校准，PLL失锁／停钟及模组故障保护保留。
- H30标识改H60，C/I计数逻辑和含义不变。60Hz是重复显示已完成的图像，不是CNN推理60fps。

## 实际验证

Efinity2026.1.132／Ti60F225 I3，单任务四线程，实际完成综合、接口生成、两次布局布线、两轮原生D-PHY拓扑／STA和本地配置生成：

| 项目 | 最终结果 |
| --- | --- |
| RAM10 | 248/256 |
| DSP | 148/160 |
| XLR | 40234/60800 |
| 最小setup／hold | **+0.319／+0.026ns** |
| D-PHY同步链 | 8条首级唯一对应第二级，0级组合逻辑 |
| 最终级间最小setup | **+13.508ns** |
| 时序约束 | 17单比特首级、136 Gray、14 FPS束、8精确D-PHY首级；不整组切异步时钟 |

全部 **79实际脚、12Bank、整份peri.xml** 与旧摄像头签核版完全一致。MIPI保持1.2V输入；SCL D12／SDA B14保持3.3V开漏、OUT恒0、复位释放；C12模组高有效复位、DDR1.5V和TMDS Bank1.8V均不变。25032字节固件、CPU HDL、四条启动RAM、传感器配置和模型指纹保持一致。

新raster／overlay三完整1650×750帧逐像素仿真通过：921600像素彩条、640×480居中、坐标／同步／安全窗口、一次欠载及下一帧恢复、C30/I02/H60的7392像素字形。FIFO/ACK为刺激模型，不是完整SoC。新实际顶层黑盒保护测试通过：I²C四状态开漏／从机ACK、三PLL分别失锁、校准失效、停钟、按键复位；校准失效保留HDMI扫描，传感器仍进入安全复位。

原采集、PPI、CPU、CNN和固件故障仿真按原始路径／原始回执及逐字节一致性复用，新增显示测试独立绑定。V7真实HDMI TX的VIC4／校验和／BCH验证明确复用同字节UART发送端的原回执；不是新摄像头整机重新完成光学或模拟输出测试。保留已记录的V7公开HS间隔±1像素差异、保护区位宽／未驱动线提示及原板级HDMI邻近耦合警告，不称零警告或HDMI合规认证。

原九套发布的源／配置／报告／bit保留。实物供电、模组包模式、Bayer、曝光、摄像头出图、真实DDR/CPU/CNN/HDMI并发与FPS尚需本次上板验证。原640×480单模型仿真等效约2.136fps，当前结构仍达不到赛题>15fps，不能因改为60Hz显示就宣称整题完成。

## 本地构建入口

首次候选生成 `scripts/hdmi60/build.py prepare`（拒绝覆盖既有候选）；先跑 `sim/check_display60.py` 和 `sim/check_top_safety60.py`，再 `scripts/hdmi60/build.py compile`。该流程先完全计时路由，证明D-PHY首级拓扑后再最终路由、最终证明、签核和bit生成；既有文件复核为 `scripts/hdmi60/build.py audit`。工作目录使用本项目build；运行中不改源、固件或权重。vendor／build／sim／C按现有Git范围仅留本地。
