# RISC-V 控制软件

本目录用于赛题一的 Ti60F225 / Sapphire RISC-V 控制软件。目前仅建立目录和职责说明，尚无应用代码，也未完成编译或上板验证。实施目标见 [赛题一实施计划](../../../../docs/赛题一实施计划.md) 的 P6、P7 阶段。

## 目录

```text
software/
├─ README.md       本说明与进度
├─ src/            应用入口、调度和手写驱动
├─ include/        驱动接口及与 RTL 共用的寄存器定义
├─ platform/       本板 Sapphire 配置、启动与链接相关文件
└─ docs/           寄存器表、内存布局、启动日志和验证记录
```

当前子目录为空；确定工程入口及接口后再放入文件。厂商 SDK/BSP 的完整拷贝不放在这里，使用时记录来源和版本。

## 负责范围

1. 启动与诊断：串口输出版本、板卡/时钟信息；确认 DDR 校准、外设就绪和错误状态。
2. 摄像头控制：按实际传感器型号配置 I²C 寄存器、读取芯片 ID 和状态，并记录配置结果。现有摄像头示例由 RTL 发起 I²C 配置；软件接管前需与 RTL 同学约定唯一控制者及复位顺序。
3. 推理控制：加载模型权重，设置输入/输出地址和尺寸，启动加速器，处理完成中断、超时和错误。
4. 帧管理与显示：维护采集帧、推理帧和显示帧的所有权；只发布已写完的完整帧，并确保原画与风格画对应同一 `frame_id`；控制模式切换与 FPS 显示。
5. 性能记录：分别统计采集帧、推理完成帧和显示刷新，记录丢帧、溢出、错误及端到端延迟。

## 与 RTL/算法组待确定的接口

在写驱动前，需要共同确认以下内容，并存入 `docs/`：

- Sapphire 的 CPU 时钟、串口、I²C、定时器、DDR 和中断配置，以及软件启动地址。
- 外设寄存器地址表：偏移、位定义、读写属性、复位值、启动/完成/清中断顺序。
- DDR 帧池地址、对齐、stride、像素格式与字节序；CPU 与 DMA 的缓存一致性方案。
- 模型权重的格式、大小、存放位置、加载方式与版本校验。
- 摄像头配置由软件接管的时机；显示模块的换帧握手和状态反馈。

上述地址与参数暂不猜测。接口确定后应将常量集中到 `include/`，让驱动、RTL 接口文档与测试使用同一版本。

## 第一阶段验收

1. 固定可复现的 Sapphire 工程、工具链版本和启动方式；串口打印固件版本。
2. 读到预期的摄像头 ID，记录初始化成功/失败；此步骤以实际硬件连接和 I²C 控制权已确认作为前提。
3. 使用最小测试任务启动一次加速器，收到完成中断或状态，核对输入/输出地址及结果。
4. 留存构建命令、启动日志和实测结果；未上板的功能标记为“未验证”。
