# RISC-V 控制接口

Sapphire 3.4.0 新实例：100MHz，RV32I/Zicsr，32KB RAM，复位地址 `0xF9000000`。APB 基址 `0xF8100000`，PLIC 基址 `0xF8C00000`，外部中断 ID 16。外设 I²C 由 C 驱动使用 APB 开漏 GPIO 实现；像素 DMA 使用独立 AXI128 总线。

| 偏移 | 功能 |
|---|---|
| 0x00 | 只读标识 0x53565931 |
| 0x04 | bit0 允许采集；bit1 释放模组复位；bit2 FPS 叠加 |
| 0x08 | bit0 作业忙（含显示提交）；bit2 最新原图有效；bit3 权重有效 |
| 0x0C / 0x10 | IRQ 状态 W1C / 掩码：完成、推理错误、采集错误、按键 |
| 0x14 / 0x18 | 最新源帧 ID / CNN 作业周期数 |
| 0x1C / 0x20 / 0x24 | 推理完成帧 / DDR 发布采集帧 / 跳过与错误帧数 |
| 0x28 | 最新请求风格（按键也更新） |
| 0x2C | 读：已加载风格；写：下一次加载目标，忙时不可改 |
| 0x30 | bit0 START、bit1 BEGIN LOAD、bit2 COMMIT WEIGHTS |
| 0x40 / 0x44 | bit1 SCL、bit0 SDA，写1释放/0拉低；读同步后的实际电平 |
| 0x48 | 100MHz tick，用于 I²C 延时与拉伸超时 |
| 0x50 / 0x54 / 0x58 | 配置地址 / 数据 / 合法写次数 |
| 0x60 | 固件启动状态：1 复位、2 配置、3 采集；最高位标记错误 |

权重地址 `[15:14]`=类别（0 int8 权重、1 int32 偏置、2 右移），`[13:11]`=层号，`[10:7]`=tap，`[6:0]`=层内字节或输出通道。移位 0–31，舍入/饱和/相位特征/BN 折叠沿用既有整数参考。

每种模型 1404 权重字节 + 27 偏置 + 5 移位，共1436次合法写。硬件检查地址、计数、加载状态和忙状态；计数检查不是覆盖 CRC。实际编译固件的完整配置写序列已对照独立导出权重验证。按键在加载中变化不会错误标记当前模型。

摄像头使用7bit地址0x30，先读0x3107/08=CD/6B。所有模式、尺寸读回及初始权重加载完成后才写0x0100=1，中途开流被延后。失败时禁止采集、模组保持复位、I²C释放。读取实际0x320E/F，按线性模式将曝光限制在[4,2×VTS−11]半行；不据此推断摄像头实际帧率。
