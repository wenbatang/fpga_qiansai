原理图来源为 `elinx/elinxdemo/Ti60F225_DemoBoard_v4/Ti60F225A_V4_SCH.pdf`。PDF物理页与图纸sheet编号在第7页之后相差一页，以下明确使用PDF页码。重新查看第3、7、8、10、11、13页的完整图，DDR/HDMI/时钟/按键/UART的66脚重新运行独立原理图转录检查，再逐项增加13个摄像头脚，不只读取旧审查缓存。最终pinout的79脚、方向、Bank、电压、唯一封装脚全部核对；未分配GPIO无输出驱动。

## 最终时序与例外核对

- 当前bit对应Efinity2026.1.132、Ti60F225 **I3** 最终布局布线报告；列出的23组setup/hold关系全部非负，最小setup **+0.289ns**、hold **+0.026ns**，core内部setup **+2.690ns**。不能把26ps保持裕量写成很宽裕，也不能把数字报告当作物理信号完整性测量。
- core/CPU/CNN/解析100MHz，DDR PHY400MHz，HDMI74.25MHz与5倍串化；3300×750总周期=30Hz。摄像头byte按70MHz约束，实际由模组提供并可能停振，真实频率尚未测量。
- 在本项目build内临时重建预期约束，并与已布局布线SDC逐字节一致：17个标量首级、136条Gray最大延迟、14bit稳定FPS束、8个D-PHY控制首级及明确异步复位脚。没有新改约束、整组异步切断或多周期放宽。
- 8个D-PHY首级的最终原生STA均仅到对应第二级、0组合逻辑，最小级间setup+13.555ns；后级正常计时。原word_count→pixel_bits_cnt模块不在新映射网表，因此没有靠例外掩盖它。
- 按键/I²C是异步输入，经同步器；静态UART TX与模组RESET不是源同步数据总线。它们没有伪造外部同步setup/hold要求。DDR实际源同步端口使用厂商Interface Designer生成的I/O延迟。

## 新增保护逻辑测试与功能证据

新增 `sim/check_top_safety.py` 编译**真实顶层、board_boot和reset_sync**，只把其余IP/系统子模块黑盒化并强制状态输入。缩短上电/长按计数，验证I²C四组拉低/释放组合、从机ACK、三路PLL分别失锁、DDR校准失效、UI与byte时钟停振、组合按键复位和恢复。全部通过。该仿真用于顶层保护接线，不是完整SoC或模拟电气仿真。

后续新增 `sim/check_camera_fault_shutdown.py`，直接执行新目录中与bit初始化对应的RV32机器码，覆盖8项故障：错误ID、无模组、SDA常低、SCL常低、配置NACK、尺寸读回错误、VTS不足、开流NACK。全部进入失败状态，采集关闭、模块RESET保持有效、I²C两线释放、CNN不启动；继续执行1000条指令后不会重试开流或继续写权重。失败码分别为3/2/2/2/4/5/8/6。此为加速ISA/MMIO/I²C模型，未代替真实Sapphire/板级故障注入。收据保存在`sim/camera_fault_shutdown/verification.json`，既有生产固件/bit与旧验证收据未改。

已有且指纹仍匹配的证据：

1. 合法原厂D-PHY RX/TX、实际异步FIFO、PPI解析与Bayer联合仿真：六组相位/停振/复位用例通过；1920×1080 RAW10到640×480连续3个完整好帧、0坏帧。
2. CSI故障注入：lane偏斜、ECC/CRC、字数、包打断、丢FE、超时与FIFO溢出/复位恢复；错误帧不发布。
3. 采集FIFO/DMA、三原画所有权和写仲裁验证：半帧、背压、最终B、锁住源bank、错误恢复。生产640×480的三原画bank地址覆盖也逐字检查，38400个128bit写地址/帧，不重叠、无越界。
4. 四组真实模型运行时加载、实际CNN/DMA在缩小几何逐像素对照整数参考，RGB565误差0；不是VGA完整尺寸吞吐或板上FPS测试。
5. 真实Sapphire RTL执行当前9468字节固件，测试I²C/ID/配置、2872项两模型加载、启动与两次PLIC完成中断。摄像头及加速器完成在该CPU测试中为模型。

真实接线的数据链为：J4摄像头 → D-PHY/PPI → RAW10/Bayer裁剪640×480 → DDR原画bank4/6/8MB → 五层六通道定点CNN → 风格bank0/2MB → 最后B响应 → 安全垂直消隐提交 → HDMI720p30。CPU处理控制与调度，像素卷积在FPGA硬件执行。

SC431HAI手册第14页图1-7/1-8画出单个短包或长包分别经ST/ET/LP传输，与当前一个CSI包/HS模式一致，是支持依据；它不是当前163项模式配置对应实物波形的测量。若实物同一HS突发连续多包，目前解析器不支持，需扩展后重新验证。Bayer/亮度、真实CPU启动、DDR/HDMI并发、采集30fps与推理>15fps仍未验收。

因此本次可确认**新bit的设计连接、数字功能证据与CAD配置检查通过**。J4和1.2V跳线已确认；仍需先明确未知的上电Flash配置并测实际供电，再进入受控易失性上板验证，本轮没有执行。首次运行应测Bank供电与板级电流/温升，确认ID及实际帧计数；排线与跳线调整均在断电状态进行。摄像头手册第9页还要求DOVDD下电时控制口不得保持高电平：对本配套模组应避免板卡带电时单独插拔或断开模组供电，以免控制线反向供电；RESET与开漏释放不能代替电源隔离。时序违例通常先表现为数据错误/花屏，防止硬件受损的关键仍是实际电压、接口方向和无输出冲突。
