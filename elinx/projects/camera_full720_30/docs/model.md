# 真正720p轻量网络

本项目的输入、每层的逻辑特征图和输出均为1280×720。没有池化、stride=2、特征图缩小或2×2共享残差。DDR中的每一个源像素都参与神经网络，并得到自己的RGB残差；HDMI输出720p60。30fps指每秒完成30张不同的风格化图像，不是HDMI重复刷新的次数。

## 与上一候选的区别

| 项目 | 保留的camera_art_30 | 本项目camera_full720_30 |
| --- | --- | --- |
| 摄像头预处理/DDR/显示 | 1280×720 | 1280×720 |
| CNN内部逻辑尺寸 | 640×360 | 1280×720 |
| 隐藏通道 | 8 | 6 |
| 首层 | 3×3卷积 | 1×1卷积 |
| 空间运算 | DW3×3，d=1/2/4/8 | DW3×3，d=1/2/4/8 |
| 感受野 | 池化分支RF33，对应更大原图区域 | 原图RF31 |
| 每种风格卷积权重数 | 784 | 396，减少49.49% |
| 原图旁路 | 720p，加放大的低分辨率残差 | 720p，加逐像素720p残差 |

减少参数并不自动意味着资源按比例减少。恢复完整720p后，特征像素数变为原分支的4倍，需要增加计算并行度和行缓存；实际资源和可交付状态见验证说明与本地signoff.json。

## 网络计算

```text
RGB 1280×720×3
  → stem 1×1，3→6，冻结BN折叠、定点激活
  → [DW3×3(d=1) → PW1×1(6→6) → 隐藏残差]
  → [DW3×3(d=2) → PW1×1(6→6) → 隐藏残差]
  → [DW3×3(d=4) → PW1×1(6→6) → 隐藏残差]
  → [DW3×3(d=8) → PW1×1(6→6) → 隐藏残差]
  → head 1×1，6→3，有符号RGB残差
  → 与对应原RGB相加并饱和 → RGB565 → DDR
```

四种风格为梵高、剪纸、漫画、水墨。DW及head共享，stem和四个PW层由风格条件选择，RISC-V执行完整模型配置。全部十个算子都含真实学习参数，不以颜色滤镜替代网络。每种风格396个卷积权重；四风格联合训练的可训练参数总数为747，包含共享参数、条件分支及归一化，不能把396称为整个训练模型的参数总数。

隐藏特征为uint8，量化尺度6/255；卷积权重为int8。偏置及累加器为有符号24位，舍入加法扩为25位，先加正半LSB再算术右移，激活/残差后饱和。head保留有符号范围，最后与0–255原RGB相加并夹到0–255。实际冻结模型的保守累加绝对值上界173118，低于24位范围。冻结BN折叠是推理近似，不等同于实时IN。

## 实际训练与画质对照

训练入口为工作区pycode/full720_style/train.py，网络定义network.py，独立NumPy整数参考integer.py。本轮c6_v1实际完成6000步、batch12、96×96随机训练裁剪，先浮点、冻结BN后QAT。训练裁剪用于训练采样，不代表推理缩小分辨率。

蒸馏教师是只读style_model中原槽0/3/4/5的C8整数网络，教师允许低分辨率特征，学生没有池化。损失包含内容、梯度、蒸馏、风格Gram、色彩及TV约束。使用冻结的512张训练划分；用户照片属于留出集。没有改写参考工程或旧RF33/C8模型。

## 分条与720p的关系

硬件按四个320列核心区处理，每条读352×720：左16列重叠、320列有效输出、右16列重叠。四条分别输出320×720，合计恰好1280×720。halo覆盖RF31的半径15；全局边界使用reflect101，中间条的重叠只服务卷积，不重复写入显示图像。

分条是节省片内行缓存的方法，改变调度次序，不改变像素间距，也不是将宽高减半。没有“4个格子共用一个像素”的操作。完整720p RTL/CNN/DMA必须与整幅整数参考逐像素一致才允许发布。
