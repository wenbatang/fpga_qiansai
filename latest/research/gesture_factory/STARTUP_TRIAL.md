# 上电预装十类手势实验

本实验针对 O 形0、后三指3、拇指食指小指7及弯钩9等约定手形。交付的 camera_art_ten_paint 使用本人录入模板。此次预装候选未通过十类识别门槛，没有生成新bit。

先用实际生产C提取器、RGB565与已审阅的真实照片，在控制背景上比较每类四个训练样本代表。人员分隔测试共613张，包括272张非目标。四模板候选判对66.72%，误接收144/272。第二种候选为192维→32隐藏→11输出的整数分类器，6,496个INT8系数，包含拒识。阈值和步数只用验证集选择。测试准确率85.97%，误接收19/272，9的召回为0/41。外部类别7的24张照片（22份不同文件）中19张被拒，5张被判为6。

再把该外部集合全部改用于训练（按文件内容去重，22份），补入既有中文数字资料中手形一致的1、2、4、5、6、8、9训练原图组，并将原始HaGRID中唯一正确的7完全移出此次训练。这个实验的主测试准确率84.18%，误接收16/272，9的召回24/41；另行保留的1张7被拒。两种实验的7测试集合不同，不能横向比较7的准确率。当前缺少充足的跨人员7验证样本，0、4、9的召回也不支持替换个人录入版。

板上冻结模型需先通过有效数据与数值、真实固件启动、四秒确认链路、时序和电气检查。这里的指标来自离线掩码与受控背景，尚未覆盖SC431HAI实际前景分割。

新增公开数据来源为 [Sign_Language_Dataset](https://data.mendeley.com/datasets/pwyrdzwzwf/1)，取原版ZIP中央目录中 i_love_you 类，等距挑选24张，逐项核对ZIP CRC并目视核对手形。另一数据源 [American Hand Signs Dataset](https://data.mendeley.com/datasets/37p5dgwsk4/1) 的样本带骨架标记，未用于上述训练或评分。照片不随仓库发布。

本地运行入口为 check_startup_prototypes.py、fit_startup_head.py 及其 --expanded 选项。需要实验目录 build 下相应的数据、实际 C 仿真包装库和 clean_love 源照片。两轮整数参数保存在实验 build 内，结果 JSON 记录支持样本、混淆矩阵、输入指纹及范围。
