# 自带手势模型试验记录（2026-11-03）

目标是下载 FPGA bit 后自主识别用户定义的0–9，不必本人逐个录入，保留按键录入作为可选增强。**这两轮实验未达到交付条件；没有替换任何固件、RTL、引脚配置或 bit。**

## 已固定的语义

0是五指一起弯曲围成 O，不能用握拳代替。3是中指、无名指、小指；7是拇指、食指、小指。其余完整定义与十槽对应见 README。旧本人录入版能把任意本人手形录入某槽，不能因此声称旧 bit 已有新的通用预装分类器。

## 实际做过的工作

1. 固定公开 ASL-HG 版本，下载74,646,896字节的 test parquet，保留照片的 P1–P10 人员标识。这里的来源文件名 test 不代表我们的测试集：所有 P1–P7 作为训练、P8 验证、P9/P10 测试。同一人的相邻照片不能分到不同集合。
2. 目视核对 O/F/W。O借作0；F符合用户3；W不符合。字母Y/L/X分别借作6/8/9。来源数字0、3、6、7、8、9不直接按数字重命名。
3. 获取公开 HaGRID 小样本420张（rock300、palm120），保存原人员 user_id 和边框，按人员稳定哈希分组。未下载整个1GB压缩包，只取必要 ZIP 字节范围。
4. 本机离线 MediaPipe＋GrabCut 辅助手部掩码标注。3620张候选保留3112，508漏检/不合格，不把漏检计为识别正确。不访问用户摄像头、不向远程服务上传图片。
5. 归一化最大手部连通域和亮度，形成64×64规范图。识别 CNN 输入32×32，**只用于手势，不降低720p风格转换尺寸**。
6. 分别实际训练两组小 CNN。每组按验证集挑检查点，再报告独立测试；每组的结果都保留，不能把后续实验对同一测试集的反复调参说成完全未接触的最终盲测。

## 自动标签复核与不交付原因

自动伸指判定从300张rock中选出4张7候选，但目视复核发现3张收着拇指或不清楚，只有 `2feabed4-bf1a-4a0a-866f-2066873f4e6b.jpg` 明确符合。已将另3张改为非目标，写入独立 `factory_masks_reviewed.npz`；保留原实验输入，避免改变旧训练结果的来源指纹。

复核后只有1张合格7训练照片，没有合格7验证/测试照片。上述两轮是**含未复核自动标签的诊断实验**，不能作为最终模型训练配方继续使用。后续应先补足真实、符合手形定义的7及多视角O/弯钩9，并检查掩码错误，再重做人员划分训练。自动规则或生成图不能充当真人留出测试。

原背景差分/轮廓提取在真实偏绿摄像头下的质量也未由这些离线掩码验证。下一阶段必须分别验证手部分割与数字分类，不能只换权重并假定分割问题已经解决。
