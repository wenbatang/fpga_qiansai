# 免逐手势录入的预装分类器实验

本目录研究下载 bit 后可用的板端手势分类器。**两轮试训未达交付条件，没有新免录入 bit；不能把这里的模型当作已实现的板端识别。** 保留的可下载版本仍在 `elinx/projects/camera_art_ten_paint`，它需要本人录入。测量、误差来源和标签复核详见 [EXPERIMENTS.md](EXPERIMENTS.md)。

## 本人的手形定义

|手势|明确手形|对应原风格编号|
|---|---|---|
|0|五指一起弯曲围成 O 形，不能用握拳代替|0|
|1|食指|2|
|2|食指、中指|3|
|3|中指、无名指、小拇指，拇指和食指弯曲|4|
|4|除拇指外四指|34|
|5|张开五指|7|
|6|拇指、小拇指|9|
|7|拇指、食指、小拇指|15|
|8|拇指、食指|31|
|9|食指弯钩|40|

ASL 来源仅借用外形一致的手形，不把 ASL 数字直接当作用户数字。已目视检查 O、F、W：用户3借用 F，W 是不符合定义的负例。来源中的数字0、3、6、7、8、9均不能直接按数字映射。

## 数据和验收方法

- [ASL-HG 原始论文](https://doi.org/10.1016/j.dib.2026.112492)，公开照片镜像固定到 `juanjodurillo/asl-hg` 的 `def9d1e14bdc0386b14241535f11141e1d2c970a`；CC BY 4.0。镜像的 test parquet 为 74,646,896 字节。原随机图片划分不作为我们的测试划分；重分为 P1–P7 训练、P8 验证、P9–P10 测试，同一人不跨集合。
- [HaGRID](https://github.com/hukenovs/hagrid)，公开小样本镜像固定到 `cj-mills/hagrid-sample-30k-384p` 的 `40b00da827c57b98efb5bc73f5abf49307c713d4`。按原 user_id 的稳定哈希划分人员；rock 不能直接标成7，需核查拇指也伸出。
- MediaPipe Hand Landmarker 只在本机离线辅助标注公开照片的手部轮廓，不运行在 FPGA、不上传照片、不访问用户摄像头。漏检样本记录为失败，不假称全部照片已识别。
- 小 CNN 输入为归一化手部轮廓与亮度。离线手部掩码准确率必须与板端背景提取能力分开报告。
- `runs/cnn_v1` / `runs/cnn_v2` 实际分别训练3000/6000步，按人员留出测试71.41%/79.74%；9和非目标拒识较差。自动标注的7目视复核只剩1张合格训练照片，无合格验证/测试，不支持十手势交付。已另存复核数据；原实验保留供诊断，不能作为已清洗配方继续训练。
- 模型先通过人员留出验证，再做整数参考、真实固件、完整时序/资源/电气检查。模型未通过时不生成声称免录入可用的 bit。

`data/`、`build/`、`runs/`、`results/` 仅留本地，不上传公开照片、模型权重或下载缓存。旧资料、模型和 bit 均保留。

流程说明见 [architecture.html](architecture.html)。
