# 第 5 课：一张图如何经过完整 CNN

## 1. 任务与输入

我们的任务是区分横线和竖线。类别 0 是横线，类别 1 是竖线，程序生成 6×6 小图。单通道像素是 0～1 浮点数，1 表示亮，0 表示暗。

本例每次处理一张图，没有 batch 维度。实际框架常用 `[N,C,H,W]` 表示批量、通道、高、宽；我们的输入省略 N 和大小为 1 的 C，直接用 `[H][W]`。

## 2. 先追踪形状

| 部分 | 输入形状 | 输出形状 | 作用 | 是否有可训练参数 |
| --- | --- | --- | --- | --- |
| 卷积 Conv | `6×6` | `2×4×4` | 用两个 3×3 核提取特征 | 是 |
| ReLU | `2×4×4` | `2×4×4` | 提供非线性 | 否 |
| 平均池化 AvgPool | `2×4×4` | `2×2×2` | 每个 2×2 窗口取平均 | 否 |
| 展平 Flatten | `2×2×2` | `8` | 按固定顺序排成列表 | 否 |
| 全连接 Linear | `8` | `2` | 算出两个类别分数 | 是 |
| softmax | `2` | `2` | 分数转换为概率 | 否 |

特征图上的数字不是“原图缩小版像素”，它们是卷积核响应。两个输出通道是两种特征，不是 RGB 的两个颜色。

参数数量：卷积 `2×3×3 + 2 = 20`，全连接 `2×8 + 2 = 18`，总共 38。池化和展平没有权重。

## 3. 对照代码依次看

打开 [step05_cnn_forward.py](../step05_cnn_forward.py)。

`make_image()` 准备输入与已知类别；`new_model()` 生成初始参数；`forward()` 是网络的前向计算。这三件事分开写，便于以后替换数据或加载训练好的参数。

`conv_z` 调用上一课的卷积函数两次，每个通道加自己的偏置。`activated` 对每个数做 ReLU，形状保持不变。

平均池化采用窗口 2×2、步长 2，不补边。假设一个窗口是：

```text
1 3
2 6
```

池化结果为 `(1+3+2+6)/4 = 3`。本例选平均池化是为了让下一课的反向梯度容易展开；CNN 也可以采用其他结构。

`flat` 先取通道 0 的两行，再取通道 1 的两行，每行从左到右。展平只重排数值，不把它们求和，也不创建新特征。

`logits` 为每个类别算一次“8 个输入乘权重并求和，加偏置”。这和前面的全连接神经元是同一种计算。

## 4. 分数、概率和损失

softmax 对每个分数取指数，再除以所有指数的总和，得到两个总和为 1 的概率。代码先减最大分数，数学结果不变，能避免较大分数使指数溢出。

```text
假设概率 [横线, 竖线] = [0.8, 0.2]
预测类别 = 0，因为 0.8 更大
目标类别 = 0 时，交叉熵 = -ln(0.8) ≈ 0.223
目标类别 = 1 时，交叉熵 = -ln(0.2) ≈ 1.609
```

同一预测遇到不同目标，损失不同。目标类别的概率越高，交叉熵越小。`cross_entropy()` 采用等价的稳定计算公式，不会先把概率裁剪掉再求对数。

## 5. 运行和观察

```powershell
python study/step05_cnn_forward.py
```

程序依次打印原图、两张卷积结果、ReLU、池化、8 个展平值、2 个分数、2 个概率和损失。对照上表数一遍元素数量。

这节课没有更新权重，预测对了也可能只是巧合。不能仅看一个随机模型的结果就说它学会了。

把 `target = 0` 改成 1，再运行，会生成竖线输入。把 `image = make_image(target)` 改成 `image = make_image(target, position=3)`，观察图案位置变化怎样影响特征图。
