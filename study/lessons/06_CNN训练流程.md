# 第 6 课：让 CNN 的卷积核也学起来

## 1. 本课新增什么

前向计算继续复用第 5 课。新增的是训练数据、反向传播、参数更新和训练后的评估。训练的不只是最后的分类层，还包括卷积核和卷积偏置。

学习任务仍然是合成的横线/竖线分类，不涉及风格迁移。

## 2. 训练代码先读主流程

打开 [step06_cnn_training.py](../step06_cnn_training.py)，先看 `train()`，暂时跳过梯度细节。

```python
cache = forward(image, model)
gradients = backward(image, target, model, cache)
update(model, gradients, learning_rate)
```

前向得到预测和中间值；反向利用预测、目标和中间值计算梯度；更新根据梯度修改参数。交叉熵的求导公式直接写在 `backward()` 中，所以不需要先调用损失函数才能计算梯度；`evaluate()` 会显式计算损失用于观察。

一轮 epoch 看完训练集里的 16 张图。与第 2、3 课不同，这里每个样本更新一次参数，即 batch size 为 1 的 SGD。一轮更新 16 次。`shuffle` 每轮打乱样本顺序，随机种子固定，便于重复观察。

## 3. 反向传播一步一步读

### 第一步：从损失到两个分数

softmax 配合交叉熵时，有一个简洁结果：

```text
dlogits = probabilities - one_hot(target)
```

`one_hot` 表示正确类别位置为 1，其他位置为 0。假设概率 `[0.6, 0.4]`，目标是横线 0，则梯度为 `[-0.4, 0.4]`。梯度下降会尝试提高正确类别的分数、降低错误类别的分数。

代码先复制概率列表，再把目标位置减 1。`[:]` 是复制，避免把缓存里的原始概率修改掉。

### 第二步：从全连接层到特征

全连接输出 `z = Σ(weight × flat) + bias`。

因此权重梯度是 `dlogits × flat`，偏置梯度是 `dlogits`。一个输入特征影响两个输出分数，所以 `dflat[i]` 要把两个类别的 `dlogits × weight` 相加。

### 第三步：经过展平、池化和 ReLU

展平没有改变数值，反向只把梯度放回原位置。索引 `channel*4 + row*2 + col` 对应上一课的“通道 → 行 → 列”顺序。

平均池化的输出为四个输入的和除以 4，因此每个输入分到输出梯度的 1/4。本例窗口不重叠，每个位置只接收一次池化贡献。

ReLU 的输入大于 0 时保留梯度，小于 0 时梯度为 0。在恰好为 0 的位置不可导，本例选择梯度 0。判断要看激活前的 `conv_z`。

### 第四步：经过卷积

对某个输出位置：核权重梯度是 `该输出的梯度 × 对应输入像素`。同一个核用于所有位置，因此要把这些位置的贡献累加到同一个核元素。

`dkernels[channel][ky][kx] += ...` 里的 `+=` 很关键。写成 `=` 会只保留最后一个位置的贡献。偏置梯度同样对这个通道的所有输出位置求和。

本例卷积层之前没有其他可训练层，所以不用继续算对原始图像的梯度。如果以后把多个卷积层串联，就需要继续向前传递输入梯度。

### 第五步：统一更新

`update()` 对所有参数执行 `parameter -= learning_rate * gradient`。反向期间尚未更新参数，保证这些梯度来自同一次前向状态。

## 4. 测试集与训练集

训练集有 `2 类 × 4 个位置 × 2 组噪声 = 16 张图`；测试集有 `2×4×4 = 32 张图`。噪声种子不同，测试图不参与参数更新，但使用相同类型和相同位置范围。

这个测试只能说明模型在这个小型合成任务上的效果，不能说明它认识真实摄像头图像，也不能证明未见位置或未见形状的泛化能力。日志里的正确率是分类正确数除以样本数；它与损失是两个不同指标。

默认参数下，训练损失应明显下降，训练和测试分类正确率应达到 100%。最后打印两张新图的预测和一个训练后的卷积核。每次运行都从初始参数重新训练，本例没有保存模型文件。

先把 `epochs=100` 改成 1，观察训练不足。再恢复 100。尝试把 `learning_rate=0.05` 改成 0.01，比较同样轮数下的损失，不要同时改噪声或结构。

## 6. 训练与推理的区别

```text
训练：输入图 + 目标 → 前向 → 损失/反向 → 修改参数 → 重复
推理：新输入图 + 已训练参数 → 前向 → 预测
```

推理不需要目标，不需要计算梯度，也不应继续修改模型参数。比赛中通常在 PC 上训练，把训练后的参数加载到 FPGA，硬件执行前向计算。

我们的 FPGA 后续学习可以对应这些计算：卷积中的乘加、ReLU 的符号判断、池化累加、权重存储和输出通道调度。还需另学量化比例、累加位宽、舍入和饱和，不能直接把浮点代码当成定点硬件规范。
