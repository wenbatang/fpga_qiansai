# 第 1 课：一个神经元到底在算什么

本课只学前向计算：给它输入和参数，算出输出。暂时不讨论训练，也不需要微积分。

## 1. 先认识四个东西

| 名字 | 代码 | 本例中的意义 |
| --- | --- | --- |
| 输入 | `inputs` | `[2.0, 3.0]`，交给神经元的两个数 |
| 权重 | `weights` | `[0.5, -1.0]`，分别与两个输入相乘 |
| 偏置 | `bias` | `0.2`，在乘积求和后额外加上 |
| 激活函数 | `relu` | 决定乘加结果怎样变为输出 |

权重不是“百分比”，可以为正、为负，也可以大于 1。偏置是一个可调的数，不是代码错误。后面训练时，权重和偏置会被调整。

本例的公式：

```text
z = x0 × w0 + x1 × w1 + bias
output = ReLU(z)
ReLU(z) = max(0, z)
```

`z` 是激活前的结果。输入的下标从 0 开始，所以两个输入叫 `x0`、`x1`。

## 2. 先手算一次

```text
第一项：2.0 × 0.5  =  1.0
第二项：3.0 × -1.0 = -3.0
乘积之和：1.0 - 3.0 = -2.0
加偏置：-2.0 + 0.2 = -1.8
ReLU：max(0, -1.8) = 0
```

所以最终输出是 0。神经元内部确实做了乘法和加法，只是最后被 ReLU 截成了 0。

## 3. 对照代码逐段读

打开 [step01_neuron.py](../step01_neuron.py)。

第一段 `def relu(value):` 定义函数。`return max(0.0, value)` 把 0 和输入比较，返回较大的那个。

第二段 `def neuron(inputs, weights, bias):` 把神经元的计算放进函数。先检查输入与权重数量一致，避免少算一项。

```python
total = 0.0
for index in range(len(inputs)):
    product = inputs[index] * weights[index]
    total += product
```

`len(inputs)` 是 2，`range(2)` 依次给出 0、1。`inputs[index]` 取第 index 个输入；同一个 index 取对应权重。`total += product` 等价于 `total = total + product`，把每一项加进总和。

随后 `z = total + bias` 加偏置，`output = relu(z)` 调用激活函数。`print` 用于观察中间结果，`return output` 把结果交回调用者。

第三段 `main()` 准备数据并调用 `neuron`。它里面的参数是手工给定的。

最后的 `if __name__ == "__main__":` 表示直接运行这个文件时调用 `main()`；以后别的文件导入它时，不自动运行示例。
