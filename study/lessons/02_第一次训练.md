# 第 2 课：权重怎么学出来

先完成第 1 课。本课使用 `prediction = weight × x + bias`，不加 ReLU，让更新规律更容易看清。

## 1. 数据和任务

给程序四组数据 `(x, target)`：`(0,1)、(1,3)、(2,5)、(3,7)`。我们知道规律是 `y = 2x + 1`，程序只使用样本来计算误差，并不知道答案参数是 2 和 1。

目标是从 `weight=0、bias=0` 出发，逐渐靠近这两个参数。

## 2. 一轮训练的顺序

```text
样本 → 预测 → 与目标比较 → 损失 → 梯度 → 更新权重和偏置
                  ↑                                  |
                  └────────── 下一轮使用新参数 ──────┘
```

损失使用均方误差 MSE：先算每个样本的 `error = prediction - target`，平方后，对这一批样本取平均。损失是评估错误的一个数，不是模型的预测输出。

梯度表示“参数略微增加时，损失怎样变化”。正梯度意味着减小这个参数有助于降低当前损失，负梯度意味着增大这个参数有助于降低当前损失。步子过大可能反而增加损失。

## 3. 手算第一次更新

初始预测全是 0，所以误差是 `[-1, -3, -5, -7]`。

```text
loss = (1 + 9 + 25 + 49) / 4 = 21
grad_weight = 平均(2 × error × x) = -17
grad_bias = 平均(2 × error) = -8

learning_rate = 0.05
weight_new = 0 - 0.05 × (-17) = 0.85
bias_new   = 0 - 0.05 × (-8)  = 0.40
```

`2 × error × x` 来自对平方误差求导。现在先理解公式怎样进入代码，后面用链式法则逐层计算梯度。

## 4. 对照代码

打开 [step02_training.py](../step02_training.py)。

`samples` 保存已知答案的样本，这叫监督学习。`for epoch in range(epochs)` 重复处理数据；本例每个 epoch 用完整的四个样本，更新一次参数。

内层循环依次完成预测、误差、损失累加和梯度累加。循环结束除以样本数，才得到平均损失和平均梯度。

```python
weight -= learning_rate * grad_weight
bias -= learning_rate * grad_bias
```

这两句就是梯度下降。`learning_rate` 是学习率，控制每次改变参数的幅度。所有梯度都在旧参数上算好，再一起更新。

训练中的日志在更新前打印：同一行的 loss 与 weight、bias 对应同一个状态。

## 5. 运行与修改

```powershell
python study/step02_training.py
```

第一行 loss 为 21，第二行参数为 0.85 和 0.40。最后 weight 接近 2、bias 接近 1，新输入 4 的预测接近 9。

先把 `train()` 改成 `train(epochs=10)`，看训练不足时的误差。再改成 `train(epochs=200, learning_rate=0.01)`，观察相同轮数下变化更慢。恢复默认参数后再进下一课。
