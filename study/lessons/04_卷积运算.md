# 第 4 课：卷积核怎样读一张图

## 1. 图像变成二维数字

本课用 4×4 单通道矩阵表示图像。每个位置是一个像素数值，先不考虑 RGB。二维列表 `image[row][col]` 用行、列定位像素，从左到右、从上到下读取。

卷积核是较小的权重矩阵，本例是 3×3。它读取输入里的一个 3×3 窗口，每个像素乘对应权重，加总后加偏置，形成一个输出。

## 2. 先手算左上角

```text
输入窗口        卷积核
1  2  3         1  0 -1
5  6  7         1  0 -1
9 10 11         1  0 -1

输出 = 1×1 + 2×0 + 3×(-1)
     + 5×1 + 6×0 + 7×(-1)
     + 9×1 +10×0 +11×(-1) = -6
```

窗口向右移动一个像素，再算一个输出。第一行算完，向下移动一个像素，继续。所有位置使用同一组卷积核权重，这叫权重共享。

深度学习代码通常把这种“不翻转卷积核”的互相关也称为卷积。本教程沿用这个习惯，代码不翻转 kernel。

## 3. stride、padding 和尺寸

`stride` 是每次移动距离，本例为 1。`padding` 是在边缘补的像素宽度，本例为 0。这种不补边的卷积叫 valid 卷积，只算窗口完整落在图像内的位置。

尺寸公式分别应用于高和宽：

```text
输出尺寸 = floor((输入尺寸 + 2×padding - 核尺寸) / stride) + 1
本例：floor((4 + 0 - 3) / 1) + 1 = 2
```

所以 4×4 输入变成 2×2 特征图，边缘不会凭空补零。

## 4. 对照四层循环

打开 [step04_convolution.py](../step04_convolution.py)。

- `row、col`：输出位置，也就是输入窗口的左上角位置。
- `ky、kx`：卷积核内部的行列位置。
- `image[row+ky][col+kx]`：当前窗口内的像素。
- `kernel[ky][kx]`：对应权重。
- `value += ...`：把每一个乘积累加。

每算一个输出先设 `value = bias`；本例偏置是 0。不要把前一个窗口的累加值带入下一个窗口。

## 5. 运行和小实验

```powershell
python study/step04_convolution.py
```

输出 2×2 矩阵的四个数都是 -6，因为输入每行都是等间隔递增。

把卷积核全部改成 1，左上角输出应为 `1+2+3+5+6+7+9+10+11 = 54`。再把调用改成 `conv2d_valid(image, kernel, bias=1.0)`，每个输出应多 1。

这里的核由我们手工指定，行为类似一个固定滤镜。CNN 中的核也做这个乘加运算，但权重通常由训练得到。手写边缘滤波本身不能证明实现了神经网络风格迁移。

## 6. 接下来扩展通道

一个核产生一张特征图，多个核产生多张特征图。RGB 输入有 3 个输入通道，此时一个输出通道需要对所有输入通道的卷积结果相加，再加一次偏置。

常见卷积权重的维度顺序是 `[输出通道][输入通道][核高][核宽]`。本教程后两课只用一个输入通道、两个输出通道，便于先看清流程；代码把那个大小为 1 的输入通道维度省略了。
