# 待传输图片

把你自己的 **1280×720** PNG/JPEG/BMP 图片复制到本目录。

PC 脚本读取图片，转换成小端 RGB565 原始像素，再通过串口传给 FPGA。FPGA 不解码 JPEG/PNG。

默认严格检查图片尺寸。需要保留比例缩放并补黑边时，显式使用 `--resize`。

GUI入口为`../pc/send_image_gui.py`，可直接点击图片预览、选择串口和波特率。命令行入口`../pc/send_image.py`的交互选择支持编号或文件名，例如`1`或`0001.png`。

图片按现有 Git 规则留在本地，这份说明文件使队友克隆后也能得到预留目录。
